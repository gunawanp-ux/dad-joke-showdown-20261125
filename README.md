# Dad Joke Showdown entry

An entry for the [Dad Joke Showdown](https://make.fun/bounty/u-mfnakmal-dad-joke-showdown-1d2ce3e5) bounty on make.fun.

## The joke

> I told my son the gravy was the best storyteller at the table. It always thickens the plot.

## How it works

`main.py` writes that one original dad joke (91 characters, within the
1–200 character gate) to `/output/entry.txt`, creating the directory if
needed, and checks the length against the gate before writing.

Run it with:

```sh
python3 main.py
```

Then read back `/output/entry.txt` to verify the joke.
